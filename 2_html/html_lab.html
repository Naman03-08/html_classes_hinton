Bash Commands I have Learnt

1. touch

File Creation

The Touch command creates a new , empty file. if the file already exists, it simply updates the file's last-modified time stamp instead of changing the content. Its one of the simplest ways to create a file directly from the terminal

Syntax: touch filename

Example: Touch Notes.txt

Output: (no output - the file notes.txt is created silently in the current folder )

. mkdir

Folder Creation

The mkdir command creates a new , empty folder(directory) at the location you specify

Syntax: mkdir filename

Example: mkdir project

Output: (no output - the folder project is created silently in the current directory)

3. cd

Changing directory

The cd command changes the current working directory, moving you into a different folder in the terminal

Syntax: cd foldername

Example: cd project

Output: (prompt changes to show you are now inside ~/project )
